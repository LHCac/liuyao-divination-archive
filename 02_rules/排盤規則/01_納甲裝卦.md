# 納甲裝卦

## 主題摘要

本檔整理六爻排盤中的納甲規則，作為 Rule Engine 裝配六爻地支與五行的正式技術來源。

核心原則：

```text
先分內卦（初、二、三爻）與外卦（四、五、上爻）
→ 依八卦納甲表裝入地支
→ 再由地支取得五行
```

## 陰陽卦排列方向

### 四陽卦

乾、震、坎、艮。

由初爻往上依序排入納甲地支。

```text
乾：子 → 寅 → 辰｜午 → 申 → 戌
震：子 → 寅 → 辰｜午 → 申 → 戌
坎：寅 → 辰 → 午｜申 → 戌 → 子
艮：辰 → 午 → 申｜戌 → 子 → 寅
```

### 四陰卦

坤、巽、兌、離。

由初爻往上依陰支次序排入：

```text
坤：未 → 巳 → 卯｜丑 → 亥 → 酉
巽：丑 → 亥 → 酉｜未 → 巳 → 卯
兌：巳 → 卯 → 丑｜亥 → 酉 → 未
離：卯 → 丑 → 亥｜酉 → 未 → 巳
```

> 程式實作時不需要用「順排／逆排」自行推猜；以本表作為 deterministic lookup table 最安全。

## 六爻裝配流程

```text
1. 取得本卦下卦（初爻～三爻）
2. 查下卦的內卦納甲地支
3. 依初、二、三爻順序裝入
4. 取得本卦上卦（四爻～上爻）
5. 查上卦的外卦納甲地支
6. 依四、五、上爻順序裝入
7. 由地支取得五行
8. 再以卦宮五行推六親
```

## 變爻納甲

動爻變化後，變爻的地支應以**變卦對應爻位的上／下卦納甲**重新取得，不可沿用本卦原爻地支。

```text
If 初～三爻為動爻
Then 查變卦下卦的內卦納甲

If 四～上爻為動爻
Then 查變卦上卦的外卦納甲
```

變爻六親仍以本卦所屬卦宮五行為基準計算；本檔只負責地支裝配。

## Rule Engine 使用規則

```text
If 上卦或下卦無法辨認
Then 停止納甲，不可猜測

If lookup table 找不到八卦
Then 回報規則資料缺失

If 本卦與使用者手動輸入卦名不一致
Then 先停止排盤並重新核對六爻輸入
```
