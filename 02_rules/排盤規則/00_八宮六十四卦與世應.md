# 八宮六十四卦與世應

## 主題摘要

本檔整理京房八宮六十四卦的宮位、八宮序位與世應位置，作為六爻排盤時判定卦宮與世應的正式技術規則來源。

使用順序：

```text
先確認本卦
→ 查所屬八宮
→ 查八宮序位（八純／一世／二世／三世／四世／五世／游魂／歸魂）
→ 依序位定世爻與應爻
```

> 不可只靠卦名記憶世應；必須先核對卦宮與八宮序位。

## Rule Engine 使用規則

```text
If 已知本卦
Then 先由上卦＋下卦取得唯一卦名
Then 用本表取得 palace、palacePosition、世爻、應爻

If 找不到本卦對應八宮序位
Then 停止排盤，不可猜測世應

If 其他文件的世應與本表衝突
Then 回查原始八宮表與八宮序位，不可只憑舊案例修正
```
