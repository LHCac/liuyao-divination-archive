# 因果式解卦輸出模板

## 主題摘要

此模板用於輸出較完整、具有前因後果、又能讓使用者快速取得明確方向的六爻解卦內容。

目標同時做到兩件事：

1. **先回答「所以到底怎樣？」**，讓使用者先拿到可參考的方向。
2. **再完整說明「為什麼這樣判」**，尤其補足六個爻位的角色、旺衰、動靜、作用與現實翻譯。

此模板適合正式解卦、複雜卦、多動爻、感情、事業財運、健康、失物、重大決策等需要完整推理脈絡的情況。

## 使用原則

正式解卦時，先照 `00_六爻解卦SOP.md` 完成排盤與檢查，再用本模板輸出。

```text
SOP = 判斷流程
因果式模板 = 輸出格式
```

### 核心輸出原則

```text
先給明確方向
↓
再給三個主要理由
↓
完整排盤
↓
六爻逐爻解析
↓
動爻深挖
↓
世、應、用神分線
↓
發展路徑
↓
建議
↓
應期 / 時間邊界
↓
一句話總結
```

### 明確答案不等於武斷

使用者通常希望知道「偏向會不會、能不能、好不好、值不值得」，因此結論要盡量明確，不要只用「都有可能、再看看」迴避判斷。

但如果卦象本身訊號矛盾，也不能為了明確而硬判。

建議固定使用以下支持度：

| 支持度 | 使用方式 |
|---|---|
| 高支持 | 核心用神、世應、動變多數同向 |
| 中高支持 | 主方向明確，但有一兩項重要阻力 |
| 中等支持 | 有條件成立，成敗點清楚 |
| 中低支持 | 有一些機會，但阻力大於助力 |
| 低支持 | 核心用神、世應、動變大多不支持 |
| 無法明判 | 核心訊號互相衝突，證據不足以定方向 |

## 重要規則

如果使用者提供的範例格式中有排盤、旬空、六親、卦宮或旺衰錯誤，必須在解卦時主動修正，不能為了照格式而延續錯誤。

```text
格式可以學
錯誤不能跟
```

另外：

```text
逐爻解析 ≠ 六爻權重相等
```

動爻、用神、世應、月日旺衰仍是主判斷；靜爻主要提供背景、條件、資源、阻力與細節，不得因為逐爻分析就把弱靜爻放大成主結論。

## 一、結論先行區

正式解卦一開始先回答使用者最想知道的結果，再進入技術細節。

### 建議格式

```text
## 結論先說

判斷：偏向會 / 偏向不會 / 有機會但條件不足 / 目前不利 / 無法明判
支持度：高 / 中高 / 中 / 中低 / 低

一句核心判斷：
這件事目前比較像……，不是……。

最主要三個原因：
1. ……
2. ……
3. ……
```

### 原則

```text
先回答方向，再證明方向。
```

如果問題是感情、工作、合作、求財等，可以直接回答：

```text
有沒有機會？
對方有沒有推進力？
目前成不成？
最大卡點是什麼？
```

但要避免把象徵性解讀說成客觀事實或讀心。

```text
5. 是否有需要修正的地方
```

## 四、占問類型與用神設定

### 建議格式

```text
🔮 占問類型與用神

占問類型：
用神設定：

- 用神：代表什麼
- 原神：代表什麼
- 忌神：代表什麼
- 仇神：代表什麼
- 世爻：問卦者 / 事件主體
- 應爻：對方 / 外部環境 / 指定對象
```

### 目的

必須先讓使用者知道「為什麼取這個用神」。

例如：

```text
問業績 → 妻財為用神
問健康 → 官鬼為病因，子孫為康復
問腦波調頻 → 父母看調頻內容、引導、儀器與資訊；世爻看自己承受狀態；子孫看放鬆恢復；官鬼看壓力干擾
問感情 → 依男女與問題角度取官鬼、妻財、應爻
```

### 人物題特別提醒

指定人物題要區分：

```text
應爻 = 這個人目前在事件 / 關係中的實際位置
官鬼 / 妻財 = 感情角色、職位角色或問題類型對應角色
```

兩者不一定永遠呈現相同狀態。若「人」與「角色」狀態不一致，這個差異本身可能就是關鍵判斷點。

## 五、六爻逐爻完整解析區

六個爻位都要解釋，但必須標示主次。

### 每一爻固定檢查

| 項目 | 要回答的問題 |
|---|---|
| 爻位 | 位於事件哪一層、哪一階段 |
| 六親 | 在本題代表什麼 |
| 六神 | 補充什麼人物風格、氣氛、細節 |
| 地支五行 | 與其他核心爻有什麼基本關係 |
| 月日旺衰 | 臨、合、破、生扶、克泄耗、日沖等 |
| 旬空 | 是否落空、等待出空 |
| 動靜 | 能否主動發力，或只能作背景 |
| 世應 | 是否為當事人、對方、指定人物 |
| 生剋沖合 | 實際和哪些爻產生有效作用 |
| 變爻 | 若明動，化何爻、進退、生剋沖合如何 |
| 現實翻譯 | 放回題目最可能呈現什麼 |
| 重要度 | 核心 / 次要 / 背景 |

### 建議格式

```text
### 初爻：○○○【核心 / 次要 / 背景】
- 六親 / 六神：
- 月日旺衰：
- 動靜 / 空破合：
- 與世應用神關係：
- 現實翻譯：
- 對總結論影響：

### 二爻：○○○
……

一路分析到上六。
```

### 逐爻分析原則

```text
每一爻都說明「它是什麼」與「它在本題做什麼」。

靜爻可以很旺，但若沒有暗動或其他有效作用，不能因為旺就說它主動做了某件事。

弱靜爻可以提供背景，但不得蓋過用神、世應與動變。
```

## 六、動爻深挖區

所有真正明動爻要從逐爻區再拉出來深挖。

### 固定順序

```text
原爻是什麼
→ 為什麼重要
→ 化出什麼
→ 回頭生 / 回頭剋 / 進神 / 退神 / 沖 / 合 / 伏吟
→ 變爻旺衰
→ 原動爻對其他本爻產生什麼作用
→ 對未來趨勢造成什麼改變
```

### 動爻爻辭

只引用**本卦真正發動爻位的爻辭**。

```text
技術結構先判
↓
真正動爻爻辭補充
↓
兩者若一致，互相加強
↓
若不同，仍以用神旺衰、動變、世應為主
```

不得把變卦同位置爻辭當成本卦動爻爻辭使用。

## 七、世、應、用神三線分析

### 世爻線

回答：

```text
問事人 / 事件主體現在是什麼狀態？
主動、被動、旺、衰、空、破？
有沒有越來越投入、退縮、壓力增加？
```

### 應爻線

回答：

```text
指定對象 / 外部環境目前在什麼位置？
有沒有主動力？
跟世爻是生、剋、合、沖、比和？
```

### 用神線

回答：

```text
事情真正要成的核心條件有沒有力量？
是旺而動、旺而靜、衰而動、空破、化進、化退？
```

### 三線交叉

最後回答：

```text
「人」願不願意 / 動不動
與
「事情本身」成不成
是否一致？
```

若不一致，要明確指出差異，不能混成一句。

## 八、重點訊號總結區

此區用「一、二、三、四……」整理，且每點都要有前因後果。

### 建議格式

```text
📝 綜合論斷

一、最大正面訊號：○○○
因為……，所以……。
但同時……，因此修正為……。

二、最大阻力：○○○
……

三、用神 / 原神支撐：○○○
……

四、忌神是否形成有效傷害：○○○
……

五、世應關係：○○○
……

六、六神細節：○○○
……

七、本卦 → 變卦：○○○
……
```

---

## 九、事情發展路徑

不能只解「現在」，要把卦象整理成可能的發展順序。

### 建議格式

```text
目前狀態
→ 第一個轉折
→ 後續力量增加 / 減少
→ 最可能落點
```

例如：

```text
目前有互動
→ 用神發動
→ 但化退且變爻月破
→ 因此短期可能有發展感，後續卻容易減速
→ 最可能停在未完全落實的狀態
```

注意：發展路徑是依卦象結構整理，不是把所有細節編成必然事件劇本。

## 十、本卦與變卦補充

```text
本卦 = 目前整體背景 / 主題
變卦 = 事情經過動爻變化後的後續情境
```

卦義只能補充技術判斷，不能取代：

```text
用神旺衰
世應
動變
空破
生剋沖合
```

若卦辭、爻辭與技術結構一致，可作第二層驗證；若不一致，仍以技術結構為主。

## 十一、因果式寫法規則

### 每一點都要遵守

```text
現象 → 規則 → 修正 → 象意 → 現實翻譯 → 對結論的影響
```

### 範例句型

```text
用神雖然月破，照一般規則屬於高層次衰敗。
但它同時發動，且變爻與月建相合，形成假破動化旺。
依動變組合優先於日月短期衝擊的原則，最後不作真破論。
所以這不是完全沒機會，而是「表面受阻、內部有轉機」。
```

```text
忌神原本克用神，理論上會壓制事情發展。
但忌神發動後轉而生原神，原神再生用神，形成通關。
因此忌神不是單純破壞，反而把壓力轉成推動力。
```

---

## 十二、預測與建議分離

這一點必須明確區分。

### 卦象判斷

只回答：

```text
現在偏向什麼結果？
為什麼？
最大的成敗點是什麼？
```

### 現實建議

再回答：

```text
如果使用者希望提高成功率 / 避免浪費時間 / 降低風險，可以怎麼做？
```

不能因為建議某人「不要急」就反過來把卦解成「一定有機會」。

```text
預測 = 卦象呈現的趨勢
建議 = 根據趨勢提出的行動策略
```

兩者不可混為一談。

---

## 十三、應期與時間邊界

### 有明確時間依據時

```text
⏳ 應期推估

1. 動爻逢值：○日 / ○月
2. 變爻逢值：○日 / ○月
3. 六合應期：○日 / ○月
4. 旬空出空：○日 / ○月
5. 暗動：應期偏快，常以日計
```

### 沒有足夠應期依據時

要明確寫：

```text
本卦可判趨勢，但不足以精確指定日期。
```

如果問題本身沒有設定期間，不要硬把卦解成無限期結果。

若使用者很重視時間，可以建議下次把問題限定為：

```text
未來一個月 / 兩個月 / 三個月內……是否……？
```

### 建議格式

```text
## 最後結論

判斷：

最核心原因：

最可能發展：

最重要觀察點：

【卦象判斷】
……

【現實建議】
……

【目前不能從卦直接判定】
……

```

「不能判定」不是每卦都一定要寫，但涉及讀心、第三者、超自然、醫療、投資等容易過度延伸的題目時，應主動劃清邊界。

如果使用者只想要重點，可保留：

```text

3. 完整排盤
4. 六爻逐爻重點

```

## 阿咪重點速記

- 正式解卦使用「SOP + 因果式模板」。
- **答案先行：先告訴使用者偏向會不會、能不能、好不好，再說原因。**
- 明確不等於武斷；固定使用高、中高、中、中低、低、無法明判等支持度。
- 排盤要完整，遇到明顯錯誤要主動修正。
- **六個爻位都要說明，但權重不相等。**
- 動爻、用神、世應、月日旺衰仍是主體；靜爻主要補背景與條件。
- 動爻要獨立深挖原爻 → 變爻 → 進退生剋沖合 → 未來趨勢。
- 人物題要區分「應爻的人」與「官鬼 / 妻財等角色」。
- 預測與建議分開，不讓建議反過來污染卦象結論。
- 有時間依據才給應期；沒有就明說不能精確定日。
- 核心句型：因為……所以……；但……因此修正為……。
