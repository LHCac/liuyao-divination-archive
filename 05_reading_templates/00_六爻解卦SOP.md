# 六爻解卦SOP（標準作業程序）

## 主題摘要

本 SOP 是日後進行六爻解卦時的標準流程。使用者提供卦象資訊後，先完成排盤確認、用神設定、旺衰判斷、動爻檢查、世應分析、六爻逐爻解析、卦義與應期，再輸出結論。

本次修正版新增三個核心要求：

1. **判斷流程完整做完後，輸出時必須「結論先行」**，先回答使用者最想知道的方向。
2. **六個爻位都要解析**，但明確區分核心、次要、背景，避免把弱靜爻放大。
3. **卦象判斷與現實建議分開**，避免建議反過來污染預測。

### 一卦一案原則

```text
每一個新的占問都重新歸零。
只使用：本次問題 + 本次卦象 + 本次使用者明確提供的背景。
```

除非使用者明確要求「和上一次比較、結合之前的卦、加入之前發生的事情、做時間線比較」，否則不得把舊卦、舊人物印象、舊結論帶入新卦。

## 第一步：接收卦象資訊

問卦者需要提供下列資訊：

| 資訊 | 必要性 | 說明 |
|---|---|---|
| 占問問題 | 必須 | 股票、感情、健康、求職等，問題越具體越好 |
| 占問對象 | 必須 | 自占還是代占？對象背景是誰？ |
| 卦卡狀態 | 必須 | 六爻爻象：少陰、老陰、少陽、老陽 |
| 本卦變卦 | 必須 | 卦名，例如履卦化乾卦 |
| 月建日辰 | 必須 | 例如癸巳月、癸巳日，不可省略或自行更動 |
| 性別 / 關係角色 | 感情題建議 | 幫助正確定位官鬼、妻財與應爻 |
| 職業 / 現實背景 | 建議 | 有助於判斷用神與現實情境 |
| 時間範圍 | 建議 | 若使用者重視期限，最好限定一月、兩月、三月等 |

如果缺少的背景會直接影響用神，應先說明限制；若可以先用世應或事件結構判斷，也可先判主結構，再標示「補充背景後可再加角色層」。

## 第二步：排盤確認

### 2-1 爻象確認

| 爻象 | 代表 | 變化 |
|---|---|---|
| 少陰 | 陰靜 | 不變 |
| 少陽 | 陽靜 | 不變 |
| 老陰 | 陰動 | 變陽 |
| 老陽 | 陽動 | 變陰 |

### 2-2 上下卦確認

```text
下卦：初爻、二爻、三爻
上卦：四爻、五爻、六爻
變卦：動爻陰陽變化後形成
```

### 2-3 卦名對照

```text
下卦 + 上卦 → 對照六十四卦卦名
```

必須與問卦者提供的本卦、變卦符合。若不符合，先停止正式解析，指出差異並重新核對。

### 2-7 六神安裝


| 日干 | 初爻 | 二爻 | 三爻 | 四爻 | 五爻 | 六爻 |
|---|---|---|---|---|---|---|
| 甲、乙 | 青龍 | 朱雀 | 勾陳 | 騰蛇 | 白虎 | 玄武 |
| 丙、丁 | 朱雀 | 勾陳 | 騰蛇 | 白虎 | 玄武 | 青龍 |
| 戊 | 勾陳 | 騰蛇 | 白虎 | 玄武 | 青龍 | 朱雀 |
| 己 | 騰蛇 | 白虎 | 玄武 | 青龍 | 朱雀 | 勾陳 |
| 庚、辛 | 白虎 | 玄武 | 青龍 | 朱雀 | 勾陳 | 騰蛇 |
| 壬、癸 | 玄武 | 青龍 | 朱雀 | 勾陳 | 騰蛇 | 白虎 |

六神只作細節補象，不能取代六親、旺衰、動變與世應。

## 第三步：用神設定

依占問問題類型設定用神：

| 占問類型 | 用神 | 必要時同看 |
|---|---|---|
| 測人個性 | 應爻 | 六神補細節 |
| 感情發展 | 官鬼或妻財 | 女問男看官鬼；男問女看妻財；指定人物同看應爻 |
| 求職轉職 | 官鬼 | 父母看文件履歷，妻財看薪資 |
| 求財、股票 | 妻財 | 子孫為原神，兄弟為忌神 |
| 問健康 | 官鬼 | 官鬼為病因，子孫為康復，父母為勞損 |
| 考試功名 | 官鬼 / 父母 | 官鬼看功名，父母看學業文書 |
| 問見面出行 | 父母 | 輔看世應與應爻 |
| 測事業財運 | 官鬼、妻財 | 官鬼看事業，妻財看財 |
| 問聯繫訊息 | 父母 | 同看應爻、世應、朱雀與動爻 |
| 自占 | 世爻不主動參與生克 | 重要規則 |
| 代占 | 應爻正常參與生克 | 重要規則 |

### 指定人物題：人與角色分開

例如感情題：

```text
應爻 = 指定對象本人目前在關係中的位置
官鬼 / 妻財 = 正式感情角色 / 戀愛用神
```

兩者若狀態不同，不得硬合併；「本人有沒有動」與「正式關係角色有沒有力量」要分開回答。

## 第四步：旺衰判斷（分層次法）

按以下優先順序判斷，高層次大於低層次。

### 第一層：動變組合

```text
動爻化進神 → 趨勢增強
動爻化退神 → 後力減弱
回頭生 → 原動爻後力增強
回頭剋 → 原動爻後力受壓
變爻旺衰只看年月日
```

### 第二層：月建高級別

| 關係 | 判斷 |
|---|---|
| 臨月建，同支 | 高層次旺 |
| 合月建，六合 | 高層次有力，但可能被合住 |
| 月破，相沖 | 高層次衰敗 |

### 第三層：月建一般層次

| 關係 | 判斷 |
|---|---|
| 月生、月扶 | 一般旺 |
| 月剋、月洩、月耗 | 一般衰或休囚 |

### 第四層：日辰高級別

| 關係 | 判斷 |
|---|---|
| 臨日辰 | 高層次旺 |
| 合日辰 | 高層次有力，但可能被合住 |
| 日沖靜爻 | 旺者暗動、衰者日破 |

### 第五層：日辰一般層次

```text
日生、日克、爻生日、爻克日 → 低層參考，不直接主導旺衰
```

## 第五步：動爻與變爻檢查

每個明動爻依序檢查：

```text
☐ 1. 原動爻六親、地支、六神是什麼？
☐ 2. 化出什麼變爻？
☐ 3. 回頭生、回頭剋、進神、退神、沖、合、伏吟，還是無直接關係？
☐ 4. 變爻在月日旺衰如何？
☐ 5. 原動爻對用神、世應及其他本爻有沒有有效生剋沖合？
☐ 6. 忌神動時，有沒有貪生忘克、通關？
☐ 7. 動爻最後是增加事情力量，還是削弱後力？
```

### 動爻能量原則

```text
明動爻可對其他本爻產生生、剋、沖、合。
靜爻不能主動發力。
暗動只有生剋力，沒有沖合力。
變爻優先作用自己的原動爻；變爻之間不互相作用。
```

---

## 第六步：靜卦 / 少動爻判斷

### 第一步：察用忌

```text
用神是否持世 / 持應？
忌神是否持世 / 持應？
```

### 第二步：觀生克

```text
用神與世應之間有沒有有效生克？
靜爻不可因「五行上能生克」就當成主動作用。
```

### 第三步：看旺衰

```text
用神旺 + 世爻有氣 → 條件較佳
用神旺 + 世爻衰 → 吉中帶憂
用神衰 → 整體支持下降
```

逐項檢查後再下結論。

---

## 第七步：世應關係分析

| 世應關係 | 象意 |
|---|---|
| 世生應 | 問卦者較主動付出 |
| 應生世 | 對方 / 外部較有利於問卦者 |
| 世克應 | 問卦者較有主導或施力傾向 |
| 應克世 | 對方 / 外部對問卦者形成壓力 |
| 世應相沖 | 雙方有衝突或節奏不合 |
| 世應相合 | 雙方有牽連、黏著，也要留意合住 |
| 世應比和 | 雙方狀態接近 |
| 世應相刑 | 關係可能有不協調、別扭或反覆 |

世應只是背景結構，仍要配合動靜與旺衰，不可只看五行就下結果。

---

## 第八步：六爻逐爻解析

六個爻位全部檢查，不能只排盤後跳過。

### 每一爻至少回答

```text
1. 這一爻在本題代表什麼？
2. 六親與六神是什麼？
3. 月日旺衰如何？
4. 有沒有旬空、月破、日破、月合、日合？
5. 是明動、暗動還是靜爻？
6. 是否為世、應、用神、原神、忌神？
7. 有沒有對核心爻產生有效作用？
8. 若有變爻，動變關係是什麼？
9. 放回現實最可能代表什麼？
10. 對總結論的重要度：核心 / 次要 / 背景？
```

### 權重原則

```text
逐爻解析 ≠ 六爻權重相等
```

判斷優先權仍以：

```text
用神 / 世應
→ 明動與變爻
→ 月日旺衰
→ 空破生克
→ 其他靜爻背景
→ 六神細節
```

靜爻即使旺，也不能直接推成它主動做了某件事。

---

## 第九步：動爻爻辭、本卦、變卦

### 9-1 真正動爻爻辭

只使用**本卦真正發動爻位**的爻辭。

```text
不得把變卦同位置爻辭當成本卦動爻爻辭。
```

爻辭用來補充「這個動爻的主題」，不能取代技術結構。

### 9-2 本卦與變卦

```text
本卦 = 現在整體背景 / 主題
變卦 = 經過動爻變化後的後續情境
```

查閱：

```text
03_hexagrams/對應卦名
```

卦義只作第二層補充，不取代用神旺衰、動變、世應。

---

## 第十步：整理「事情發展路徑」

正式結論前，先把所有技術訊號整理成因果鏈：

```text
現在狀態
→ 什麼力量開始動
→ 是增加還是減少
→ 最大阻力 / 支撐
→ 最可能落點
```

例如：

```text
目前有互動
→ 感情用神發動
→ 但用神化退、變爻又受破
→ 後力不足
→ 因此短期有發展感，但更容易停在未完全落實
```

不得把因果鏈寫成「必然會發生的劇本」。

---

## 第十一步：形成明確結論與支持度

使用者通常需要一個能拿來參考的方向，所以完成技術判斷後，必須回答：

```text
所以偏向會還是不會？
有沒有機會？
目前成不成？
最大的成敗點是什麼？
```

### 支持度分級

| 等級 | 定義 |
|---|---|
| 高支持 | 核心用神、世應、動變多數同向 |
| 中高支持 | 主方向明確，有少量重要阻力 |
| 中等支持 | 有條件成立，成敗點清楚 |
| 中低支持 | 有機會，但阻力大於助力 |
| 低支持 | 核心條件大多不支持 |
| 無法明判 | 核心訊號互相衝突，證據不足 |

### 明確不等於絕對

不得為了回答明確而把「中等支持」說成「一定會」，也不得因為存在一個反向訊號就只回答「都有可能」。

---

## 第十二步：預測與建議分開

### A. 卦象判斷

```text
卦本身偏向什麼結果？
核心原因是什麼？
最大的成敗點是什麼？
```

### B. 現實建議

```text
如果使用者希望提高成功率、避免浪費時間、降低風險，可以怎麼做？
```

重要：

```text
建議不能反過來改寫卦象結果。
```

例如「建議不要逼對方」不等於「卦象一定有機會」。

---

## 第十三步：應期與時間邊界

### 一、有明確應期依據時

```text
動爻逢值逢合
變爻逢值
旬空出空
用神旺衰的逢值 / 逢沖
暗動應期偏快
```

### 二、事件時間單位

| 事件類型 | 常用應期單位 |
|---|---|
| 急性事件 | 時辰 |
| 日常事件、暗動 | 日 |
| 一般事件 | 月 |
| 長期事件 | 年 |

原則：

```text
應近不應遠
```

### 三、沒有足夠依據時

明確寫：

```text
本卦可以判趨勢，但不足以精確指定日期。
```

如果使用者問題沒有設定期間，不要把結果解成無限期。若時間本身是核心需求，建議下一卦直接限定「未來一個月 / 兩個月 / 三個月內」。

## 阿咪重點速記

- **一卦一案，新問題重新歸零。**
- 判斷流程完整做完，輸出時「結論先行」。
- 結論要給方向與支持度，不要只說「都有可能」。
- 明確不等於武斷，訊號矛盾時可以判「無法明判」。
- 六神起法：甲乙青龍、丙丁朱雀、戊勾陳、己騰蛇、庚辛白虎、壬癸玄武。
- 八純卦世在上六、應在三爻；歸魂世三應六。
- 月日旺衰、動變、世應與用神仍是主體。
- **六個爻位都要解析，但六爻權重不相等。**
- 靜爻主要補背景，不可因旺就當成主動發力。
