# 《易與人生》資料來源

本資料夾整理自胡順萍《易與人生》掃描內容，作為 `liuyao-divination-archive` 的**六十四卦義理與人生象意補充來源**。

## 書籍定位

依作者自序，本書不是六爻納甲技術書；主要以六十四卦的卦辭、爻辭為基礎，延伸到生活、生存、生命、修養與待人處世。

因此本來源：

- 可以補充卦義、爻辭情境與人生應用。
- 不取代 `02_rules`、`04_question_types`、`05_reading_templates` 的六爻技術判斷。
- 不直接覆蓋 `03_hexagrams`；若有值得提升的角度，需先比對現有卦檔再另行整合。
- 【資料庫應用推論】必須與【書籍內容】分開標示。

## 使用與複核原則

1. 來源筆記主要採摘要，不大量逐字轉錄原書。
2. 每卦保留來源頁碼與掃描批次，方便回查原頁。
3. 掃描文字若有模糊處，以頁面影像為準，不用一般易經知識自行補字。
4. 本書義理若與現有六爻實戰規則不同，保留兩者分層，不強行合併。
5. 實際斷卦仍以六爻技術層為優先，本書只作情境與義理輔助。
