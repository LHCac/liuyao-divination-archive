# 《易與人生》資料來源

本資料夾整理自胡順萍《易與人生》一書的掃描內容，作為 `liuyao-divination-archive`（六爻專用知識與案例資料庫）的**輔助來源**。目前先收錄已整理的來源筆記作為後續掃描整合基準；完整掃描仍會分批複核後逐步補入。

## 書籍定位

根據書籍自序（掃描批次一，封面／自序／目次），本書**不是**六爻納甲斷卦技術書。它以《易經》六十四卦的卦辭、爻辭為本，逐卦提出義理，並延伸應用於生活、生存、生命、修養、待人處世等層面。

因此，本書在本 repository 中的角色是：

> **「六十四卦義理與象意補充來源」**

而**不是**：

> 「六爻納甲斷卦規則來源」

## 使用原則

1. 不以本書取代既有六爻 SOP（`02_rules`、`05_reading_templates`）。
2. 不以本書的人生義理解釋，直接取代六親、世應、旺衰等六爻技術判斷。
3. 本書內容可作為六十四卦整體象意與爻辭理解的**補充**，收錄於 `99_sources`，並可提出（但不直接執行）對 `03_hexagrams` 的補充建議。
4. 實際斷卦仍優先依六爻技術規則（見 `03_與六爻資料庫的整合原則.md` 之來源優先級）。
5. 書中觀點與現有六爻資料庫或實戰案例不一致時，保留差異並列出，不強行統一、不擅自刪除任一方。
6. 尚未掃描到的書籍內容，一律標示【尚未掃描】或【待後續資料補充】，不得以整理者的易經知識或其他版本內容自行補完。

## 給複核 AI 的提醒

- 所有標示【書籍內容】的段落，皆逐頁比對掃描圖片與 OCR 後整理，若標示【OCR待人工確認】，代表整理者無法完全確認字形或斷句，請以掃描圖片為準覆核。
