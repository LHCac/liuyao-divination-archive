# 62 小過卦

來源：《易與人生》胡順萍 著，頁 240–243。以下為掃描內容摘要整理，非逐字全文轉錄。

## 1. 作者對本卦的核心定位

【書籍內容】作者以「自知自身的能力所限以行事」定位小過卦。小過是小有所超過，但作者重點放在認清能力與位置，不做超出承擔範圍的大事。

## 2. 卦辭與卦象義理

【書籍內容摘要】山上有雷，山大而雷小。作者以此提醒初階或能力有限時，要少言、多學、多做，能把小事做好比急著證明自己更重要；即使有表現，也不宜把功勞全攬在自己身上。

## 3. 六爻逐爻義理

- **初六**：飛得過高、超過自身位置，容易招凶。
- **六二**：懂得不越位、在適當角色中完成事情，可免過失。
- **九三**：沒有做好預防，反可能遭受傷害；越在競爭環境越要警覺。
- **九四**：可以變通，但前往仍要戒慎，不能死守自以為正確的位置。
- **六五**：外表條件尚未成熟時，要深入實情、親自掌握問題，而不是只從高處判斷。
- **上六**：超越過頭、飛得太高而無法落實，便成真正的災害。

## 4. 人生與待人處世應用

【書籍內容摘要】小過不是否定能力，而是提醒「先做好自己目前能做的」。把小事做好、保持謙遜、知道何處不能逞強，反而是長期上升的根基。

## 5. 可用於六爻解讀的象意補充

【資料庫應用推論】小過可補充「小幅超越、小事可行、大事宜慎、能力或位置有限、稍微過頭」等象意；是否真的不可做大事仍須依六爻技術與現實條件判斷。

## 6. 分層提醒

本章不以小過卦直接否定計畫，只作為分寸與能力範圍的義理提醒。
